| Context | Typical target latency | What 900 ms feels like |

## Why it might be 900 ms

| Layer | Typical culprit | Quick check |
|-------|-----------------|-------------|
| **Network** | High round‑trip time, packet loss | Ping the server; check MTU, DNS resolution. |
| **Application server** | Heavy CPU, GC pauses, slow code | Profile the request path; look at thread dumps. |
| **Database / Search engine** | Missing indexes, slow joins, full‑table scans | Run EXPLAIN plans; add indexes; consider sharding. |
| **Caching** | Cache miss, cold cache | Warm the cache; use Redis/Memcached; enable query caching. |
| **Infrastructure** | Under‑provisioned VMs, I/O bottlenecks | Monitor CPU, memory, disk I/O; scale horizontally. |
